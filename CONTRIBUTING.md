# Contributing

ProsperoAI is alpha homebrew software. Keep changes focused, preserve the
model-free release, and do not commit proprietary Sony material or model
weights.

Before opening a pull request:

```bash
make check
make ffpfsc
```

Describe any PS5 hardware validation separately from host-only checks. Runtime
changes should name the tested model, firmware, prompt or fixture, result, and
whether the title closed cleanly.
