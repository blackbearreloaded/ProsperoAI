# ProsperoAI - First run on a console: every page, and one answer from every kind of model.
#
# Played by the app itself (src/dev_script.cpp) when this file is the install folder's
# dev/request.txt; tools/console-run.py puts it there with a fresh token, starts the app,
# collects the report and the pictures, and waits for the app to close itself.
#
# It expects one model of each kind, found by these search words: "qwen" (text),
# "sd-turbo" (image), "stable-audio" (sound) and "kokoro" (voice). A model that is not
# installed makes its step fail, which ends the run early and says so.
